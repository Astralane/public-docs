# 小费退款

Astralane Iris 用户自动享有 SOL 小费退还资格：若发送至我们中间件的交易以更低成本成功上链执行，用户将获得相应的小费退款。小费退还机制不会改变交易执行方式，用户也无需任何额外操作即可享受该权益。

## 什么是小费返利？

由于 Solana 验证者客户端的分割 主要集中在 Jito、Agave 和 FD 之间 ，许多用户难以确定应当优先支付更高的优先费 priority fees 还是更高的小费 tips ，以确保交易成功上链。

在当前网络竞争空前激烈的情况下，用户常常因支付不必要的高额 SOL 小费而造成过度支出。事实上，许多此类交易只需支付原 SOL 小费金额的一小部分，就能以相同的速度执行。通过使用 Astralane 的验证者边车网络 validator sidecar network ，用户现在能够以**小费返利 Tip rebate** 的形式收回这部分不必要的成本损耗。

Astralane 的系统专为最小化过度支付而设计。所有通过我们基础设施发送的交易，都会经由内部 SwQoS 网络进行路由—这既提高了交易上链成功率，也会为那些实际支付金额超过链上所需最低成本的交易自动发放返利。

## 哪些交易可获得返利?

符合返利条件的交易是指那些通过 Astralane 的 SwQoS 网络成功上链并被打包进区块的交易。具体资格取决于每轮区块中的多项动态因素，包括：

* 网络拥堵和竞争程度
* Astralane 内部 Iris 网络是否从该交易中获利及获利多少
* 该交易是直接发送至 Astralane Iris，还是同时共享给了其他 RPC 及上链服务提供商

## 如何同时最大化返利与交易速度?

直接发送至 Astralane（未使用高级 nonce 机制，且用户未将交易广播至其他 RPC 或上链服务）的交易将符合更高级别的返利条件。这是因为此类交易能最大化 Astralane 内部网络成功上链的概率，从而使我们能够分配更高额的返利。

{% hint style="info" %}
通常，通过我们的 `sendTransaction` 方法发送交易可以实现更快的执行速度和更高的返利收益，因为该方法跳过拍卖环节，直接通过我们内部的 SwQoS 网络上链。

其他方法（如 `sendBundle`、`sendPaladin` 和 `sendIdeal`）也符合小费返利条件，但具体资格取决于调用这些方法时使用的配置参数。

由于交易发送始终对延迟敏感，为提高区块打包成功率，我们建议用户使用与我们同地协作的服务器（collocated server）。
{% endhint %}

## 其他可选权限：

我们根据交易流量和小费金额提供不同类型的激励措施，包括：

* 减免或免除月度费用
* 免费享受更高 TPS 容量权限
* 交易员专属测试产品免费访问权（如 gRPC、数据分片、区块顶部数据等）

## 返利记录追踪

返利额度将根据您提供的 Iris API 密钥进行追踪。您可使用该 API 密钥在我们的平台（功能开发中）查询符合条件的返利金额，并于每月末申请提现返利款项。
