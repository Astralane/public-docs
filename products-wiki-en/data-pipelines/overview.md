# Overview

Astralane empowers developers and trading teams to build custom Solana data indexes with **real-time streaming** and **historical backfilling**. Our infrastructure handles high-speed data pipelines and bulk historical dumps, enabling applications like portfolio tracking, algorithmic trading, and on-chain analytics.



### Why Astralane?

* **Realtime Indexing**: Kafka-powered streaming for instant data updates (e.g., Dex trades, token balances).
* **Historical Backfilling**: Bulk historical data dumps filtered by program IDs, accounts, or instruction arguments.
* **IDL Parsing**: Filter instructions by name/arguments if an Anchor IDL is provided. We have Comprehensive Protocol Coverage with support for 30+ DEXes and major Solana programs
* **Unmatched performance during congestion:** Ensure that your engine doesnt lag out during peak network congestion without paying for backup nodes and connection services.&#x20;
* **Prebuilt Pipelines**: Turnkey solutions for common data indexing use cases, listed in the next sections.
